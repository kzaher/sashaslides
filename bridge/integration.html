1 · DOWNLOAD THE SKILL

A zip with the Claude skill, the local bridge server, and the Python wrapper.

⬇ Download sasha-bridge.zip

2 · RUN IT

a
Unzip and install dependencies:
cd sasha-bridge
pip install -r requirements.txt
b
Start the bridge:
python wrapper.py serve
c
Point Claude Code at the skill folder (or drop skill/ into ~/.claude/skills/), then ask Claude to build slides.
