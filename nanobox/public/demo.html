The filesystem runs in-memory (FakeVm) so ls/cat/echo work in any Chromium tab. claude and codex are the REAL CLIs — the terminal proxies them to the backend (POST /api/agent), which runs the actual claude -p / codex exec and returns genuine model output. “Connect a local folder as home” makes a real directory the VM’s /root via the File System Access API, synced through the unit-tested 3-way engine.
