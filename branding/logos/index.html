Sasha Slides — six logo concepts

Each mark is one hand-authored SVG on a 0 0 256 256 viewBox, no fonts inside the mark, no raster tracing. Every mark uses exactly two paints — currentColor and --sasha-accent — and every hole is true negative space, so it can never lose contrast against the background it sits on.

  • Ink #1E1B3A Light-mode foreground
  • Paper #FFF8F0 Light background
  • Night #0D0F1C Dark background
  • Violet #6C4BF4 Light-mode accent
  • Mint #19D3C5 Dark-mode accent
  • Amber #FFB020 Tertiary: UI and lockup only, never inside a mark
The documented wrapper. One file per concept serves both backgrounds. Put the mark inside an element that sets two properties — light: color:#1E1B3A; --sasha-accent:#6C4BF4 on #FFF8F0; dark: color:#FFF8F0; --sasha-accent:#19D3C5 on #0D0F1C. The accent flips violet→mint on purpose: mint only reaches usable contrast on the night background, violet only on paper. Amber is deliberately kept out of the marks for the same reason. Note that currentColor requires the SVG to be inlined or <use>d — referenced through <img src> it falls back to black, which is still a valid light-mode rendering. None of these hues sit near Google's brand blues (#4285F4 / #1A73E8 / #174EA6).

Favicon honesty check

All six at exactly 16×16 device pixels, nothing scaled up. This row is the real test.

Tested by rendering each mark alone into a 16×16 cell in headless Chrome at deviceScaleFactor: 1, then measuring the raster. Two numbers decide it: the anchor feature (max inscribed diameter of the mark's largest shape, in device pixels at 16×16) and ink dominance (largest connected ink mass ÷ total ink). Every one of the six is structurally fat — 93–100% of each mark's mass sits in features wider than 1.3px — so thinness is not what separates them. Fragmentation is. Concept 3 has the fattest single feature of all six (5.7px, the corral rail) and still fails, because its ink scatters into four separated masses with no figure to lock onto. Concept 6 is split too, but its split is the one intentional window, so it stays one object.
