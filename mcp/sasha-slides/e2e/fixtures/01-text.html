Paths in, ids out

Why the model never reads the slide back

A candidate slide is a file on disk. The proposal call carries its path, not its bytes, so a four-slide proposal costs the same context as a one-slide proposal.

  1. Write each candidate to a temp file.
  2. Pass the paths. Never paste the markup.
  3. Wait for the pick, and trust the returned index.
